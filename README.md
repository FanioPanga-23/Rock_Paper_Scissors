# Rock Paper Scissors

## Descrição do Projeto

Este é um exercício do **The Odin Project**, uma plataforma gratuita e aberta de educação em programação.

O projeto implementa um jogo de pedra, papel e tesoura interativo, desenvolvido com HTML, CSS e JavaScript. O objetivo é colocar em prática conceitos fundamentais de programação como:

- Lógica de programação
- Interação com o usuário
- Funcções
- Loops

## Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Escolha entre pedra, papel ou tesoura
3. O computador fará sua escolha e o resultado será exibido
4. Divirta-se jogando!

## Tecnologias Utilizadas

- **HTML5** - Estrutura
- **CSS3** - Estilização
- **JavaScript** - Lógica do jogo

## The Odin Project

[The Odin Project](https://www.theodinproject.com) é um programa educacional grátis oferecido por uma comunidade de código aberto. Ele fornece um currículo completo de desenvolvimento web, desde iniciante até avançado.
